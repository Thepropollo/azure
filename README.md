# ULEAM Azure CRUD

Este proyecto contiene una API en FastAPI y un frontend estático para practicar despliegue en Azure.

Guía completa para tu práctica: [GUIA-PRACTICA.md](GUIA-PRACTICA.md)

URLs ya publicadas:
- Frontend: https://lemon-coast-022ba9e10.7.azurestaticapps.net
- Backend/API: https://uleam-webapp.azurewebsites.net

Scripts automáticos:
- `azure-deploy.sh`: publica el backend en Azure App Service usando Docker.
- `deploy-frontend.sh`: publica la carpeta `frontend/` en Azure Static Web Apps.
- `startup.sh` y `startup.ps1`: inician la API localmente en Linux/macOS y Windows.

Si quieres ejecutar el proyecto localmente, revisa la guía de práctica para los pasos de Docker, backend y frontend.
